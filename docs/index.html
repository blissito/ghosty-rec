ghosty-rec

Graba una sola ventana de macOS desde la terminal, aunque otra la tape, y la convierte en video con zooms que dirige el agente: él marca qué está haciendo y el render hace el resto.

brew install blissito/tap/ghosty-rec
GitHub

Cómo se usa

# 1. elige la ventana (por id, nunca la pantalla completa)
rec windows --json
rec start --id 651 --out demo.mov

# 2. el agente marca lo que hace mientras graba
rec mark "teclea el comando" --rect 0,40,520,60 --say "Un comando conecta el repo"
rec stop

# 3. video listo: zoom con resorte, cursor suave, fondo y subtítulo
rec render demo.mov --aspect 9:16 --no-titlebar

# fondos: macos:Sonoma, sunset, midnight, ocean, mint, foto.jpg, #hex,#hex
rec render demo.mov --bg sunset --cursor-size 3 --click ring

Por qué

Sólo esa ventana

ScreenCaptureKit con filtro de ventana: tus chats y avisos nunca salen en el video.

Zooms con intención

Los zooms salen de las marcas del agente, no de adivinar tus clics. Se quitan con "enabled": false.

Hecho para agentes

Todo responde JSON, arranca y para en segundo plano, y avisa si el texto va a salir borroso.

Look de Screen Studio

Wallpapers de tu macOS o gradientes, sombra suave, cursor grande con resorte y anillo en cada clic.

Zoom solo

Sin marcas, hace zoom en cada grupo de clics. Con marcas, va a donde el agente dice.

Sin nube

Graba y renderiza en tu Mac. 15 s de video se exportan en unos 4 s.

Para tu agente

La skill le enseña a Claude Code y a otros agentes a grabar, marcar y renderizar:

npx skills add blissito/ghosty-rec

Requisitos

  • macOS 15+ y las Command Line Tools (xcode-select --install); brew compila desde el código.
  • Permiso de Grabación de pantalla para tu terminal.
  • El comando es rec y choca con el de sox: no pueden convivir.
